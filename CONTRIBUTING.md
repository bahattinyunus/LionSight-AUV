# Katkıda Bulunma Rehberi

LionSight-AUV projesine katkıda bulunmak istediğiniz için teşekkür ederiz! 🌊🦾

## Nasıl Katkıda Bulunabilirsiniz?

### 1. Hata Bildirimi (Bug Reports)
- GitHub Issues kullanarak hataları bildirin
- Hatayı yeniden oluşturma adımlarını detaylı açıklayın
- Sistem bilgilerinizi (ROS2 versiyonu, işletim sistemi) ekleyin

### 2. Özellik Önerileri (Feature Requests)
- Yeni özellik önerilerinizi Issues bölümünde paylaşın
- Önerinin deniz koruma misyonumuza nasıl katkı sağlayacağını açıklayın

### 3. Kod Katkıları (Pull Requests)
1. Repository'yi fork edin
2. Yeni bir branch oluşturun: `git checkout -b feature/amazing-feature`
3. Değişikliklerinizi commit edin: `git commit -m 'feat: add amazing feature'`
4. Branch'inizi push edin: `git push origin feature/amazing-feature`
5. Pull Request açın

## Kod Standartları

### Python
- PEP 8 standartlarına uyun
- Docstring'leri eksiksiz yazın
- Type hints kullanın

### ROS2
- Düğüm isimlendirmelerinde snake_case kullanın
- Topic isimleri açıklayıcı olmalı

### Commit Mesajları
Conventional Commits formatını kullanın:
- `feat:` - Yeni özellik
- `fix:` - Hata düzeltmesi
- `docs:` - Dokümantasyon değişikliği
- `refactor:` - Kod yeniden yapılandırma
